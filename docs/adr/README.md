# Architecture Decision Records

ADRs dokumentieren langlebige Entscheidungen über Architektur oder zentrale technische Grenzen, wenn zwischen realistischen Alternativen gewählt wurde.

- Die erste nummerierte ADR entsteht erst bei der ersten echten Architekturentscheidung.
- Akzeptierte ADRs werden nicht stillschweigend inhaltlich umgeschrieben.
- Eine geänderte Entscheidung erhält eine neue ADR.
- Die alte ADR erhält den Status `superseded by ADR-NNNN`.
- Kleine Implementierungsdetails und einzelne Tasks erhalten keine ADR.
- Dateiname: `NNNN-kurzer-titel.md`; Grundlage ist `_TEMPLATE.md`.
- Die Agenten-Governance wird nicht als ADR geführt; ihre Source of Truth ist `AGENTS.md`.
